# РПГ-битва 

Консольная RPG-битва, игрок и противник выбирают класс персонажа и сражаются по раундам до победы. В проекте демонстрируется наследование, абстрактные классы, переопределение методов и полиморфизм в Dart

## Запуск

1. Клонировать репозиторий: `git clone https://github.com/MorastGit/flutter_lab7`
2. Перейти в папку: `cd lab7`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Что изучили

- Наследование через `extends` и вызов конструктора родителя через `super(...)`.
- Абстрактные классы и абстрактные методы
- Переопределение методов с `@override` и вызов родительской реализации через `super.метод()`
- Полиморфизм функция, принимающая `Character`, работает с любым наследником.


## Ответы на вопросы

**1. Что такое абстрактный класс? Почему нельзя написать `Character()` напрямую?**
Абстрактный класс это шаблон, который описывает общую структуру и может содержать методы без реализации. Создать его экземпляр нельзя, потому что часть методов не имеет тела

**2. Зачем нужен `super` в конструкторе наследника? Что будет если его убрать?**
`super(name: name, hp: 120)` вызывает конструктор родителя, который инициализирует общие поля. Если убрать, родительский конструктор с обязательными параметрами не получит значений и код не скомпилируется

**3. В чём разница между `@override` у `attack()` в Warrior и `takeDamage()` в Warrior? Почему второй переопределяет метод, который уже имеет реализацию в родителе?**
`attack()` в `Character` абстрактный у него нет тела, и наследник обязан его реализовать. `takeDamage()` в родителе уже реализован, но воину нужно изменить поведение сначала уменьшить урон на броню, а затем вызвать родительскую логику через `super.takeDamage(reduced)`

**4. Функция `fight(Character a, Character b)` не знает, кто реально придёт — Warrior, Mage или Archer. Как называется эта концепция и где вы её уже видели во Flutter?**
Это полиморфизм, переменная типа родителя хранит объект любого наследника, а нужный метод вызывается по реальному классу объекта.   `Widget build()` возвращает `Widget`, а внутри может быть `Text`, `Column`, `ElevatedButton` и т.д

**5. Что означает `_random` с нижним подчёркиванием в классе Character?**
Нижнее подчёркивание делает поле приватным оно доступно только внутри своей библиотеки и не видно из других файлов
